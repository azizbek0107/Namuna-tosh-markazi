# Namuna Tosh Jilo

Mijozlar uchun o‘zbek tilidagi React reklama sayti. React + Vite, alohida CSS, server va ma’lumotlar bazasisiz.

## Ishga tushirish

```sh
npm install
npm run dev
```

## Tayyor versiya

```sh
npm run build
npm run preview
```

Yig‘ilgan fayllar `dist/` papkasida bo‘ladi.

## Kontentni yangilash

`src/main.jsx` ichida xizmatlar, materiallar, matnlar va aloqa bo‘limi; `src/style.css` ichida dizayn. Xizmatlar biznes egasi bilan tasdiqlanishi kerak. Telefon, manzil va real ish rasmlari taqdim etilmagani uchun qo‘shilmagan. Tosh kompozitsiyalari CSS’da yaratilgan konseptual tasvirlar; bajarilgan ish sifatida ko‘rsatilmagan.

So‘rov shakli faqat matn tayyorlaydi va nusxalaydi; serverga buyurtma jo‘natmaydi. Telefon/Telegram manzili berilgach, to‘g‘ridan-to‘g‘ri aloqa havolalarini qo‘shish mumkin.
